# 今日日记 · `user-daily-note`

在首页直接处理当天日记里的待办。

| 项 | 值 |
|---|---|
| 文件 | `daily-note.js` |
| kind | `user-daily-note` |
| 图标 / 强调色 | `calendar-days` / `#f59e0b` |
| 默认尺寸 | 4×6 |
| 设置面板 | 有 |

## 功能

- 日历图标一键打开当天的日记；找不到时按核心 Daily Notes 的模板自动创建。
- 输入框回车写入 `- [ ] 内容` 到当天日记的指定二级小节。
- 列出该小节里的待办，勾选后直接改写日记文件里的 `[ ]` / `[x]`。
- 跟随核心「Daily Notes」插件的目录、日期格式和模板设置。
- 支持模板变量 `{{date}}`、`{{date:FORMAT}}`、`{{time}}`、`{{title}}`。

## 配置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `section` | string | `待办` | 待办写在哪个二级小节下；不存在时新建 |
| `autoCreate` | boolean | `true` | 没有当天日记时按核心插件模板创建 |

## 读写行为

- 读取：当天日记文件；核心 Daily Notes 的 `folder` / `format` / `template`。
- 写入：仅改目标小节内的任务行，使用 `app.vault.process()` 原子写入。
- 小节匹配先找完全同名标题，再接受以该名字结尾的标题（如 `🔥 待办`）。
- 勾选前会校验原行内容，文件被别处改过就提示刷新，不盲改。

## 实现备注

- 输入草稿存在模块级 `Map` 里，卡片重绘不丢正在输入的内容。
- 回车提交会检查 `event.isComposing`，兼容中文输入法。
- 样式注入 id：`hp-user-daily-note-style`。

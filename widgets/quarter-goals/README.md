# 季度目标 · `user-quarter-goals`

把当前季度计划摊开，显示整体完成度和每个目标的下一步。

| 项 | 值 |
|---|---|
| 文件 | `quarter-goals.js` |
| kind | `user-quarter-goals` |
| 图标 / 强调色 | `target` / `#ef4444` |
| 默认尺寸 | 4×6 |
| 设置面板 | 有 |

## 功能

- 自动定位当前季度的计划文件。
- 顶层复选框当作「目标」，缩进更深的复选框当作该目标下的「步骤」。
- 显示整体进度条、每个目标的完成比例，以及第一条未完成步骤。
- 点击目标或下一步，跳到计划文件对应行。
- 只读，不写任何笔记。

## 文件定位

优先找：

```
项目/计划/<年>/<年>-Q<n>.md
```

找不到当前季度时，按文件名匹配（如 `2026-Q4 计划.md`）；再找不到就回退显示目录里最新的一个季度文件，并在卡片上标注「当前季度无计划，显示 xxx」。

## 配置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `folder` | string | `项目/计划` | 计划根目录，下面按年份分子目录 |
| `quarter` | string | `auto` | `auto` = 当前季度；也可写 `2026-Q4` |
| `limit` | number | `3` | 最多显示几个顶层目标 |

## 解析规则

- 只解析 `- [ ]` / `- [x]` 复选框，跳过代码围栏。
- 缩进按最小缩进分层；最小缩进 = 顶层目标。
- 目标进度 = 目标本身 + 所有子步骤中已完成的数量。
- 没有子步骤的目标显示「待完成」，不重复显示「下一步」。

## 实现备注

- 当前季度用 `moment().month()` 计算，Q1–Q4 对应 0–11 月。
- 样式注入 id：`hp-user-quarter-goals-style`。

# 快速记录 · `user-quick-note`

把此刻的想法以带时间戳的流水条目写进当天日记。

| 项 | 值 |
|---|---|
| 文件 | `quick-note.js` |
| kind | `user-quick-note` |
| 图标 / 强调色 | `pencil` / `#7c3aed` |
| 默认尺寸 | 4×6 |
| 设置面板 | 有 |

## 功能

- 输入一句话，回车写入当天日记的指定小节，格式 `- [09:42] 内容`。
- 列出该小节当天的记录，点击跳到日记对应行（支持 Ctrl/Cmd 新标签打开）。
- 跟随核心「Daily Notes」插件的目录、日期格式和模板设置。
- 创建日记时会跳过模板里剩下的空 bullet 占位。

## 配置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `section` | string | `记录` | 记录写在哪个二级小节下；不存在时新建 |
| `autoCreate` | boolean | `true` | 没有当天日记时按核心插件模板创建 |

## 读写行为

- 读取：当天日记中 `- [HH:mm] 内容` 形式的条目，读取时拆出时间和正文。
- 写入：追加到目标小节末尾，使用 `app.vault.process()` 原子写入。

## 实现备注

- 与 `daily-note.js` 共用同一套「找日记 / 建日记 / 定位小节」逻辑。由于插件要求单文件自包含，这段是复制而不是共享模块；改一边时记得同步另一边。
- 输入草稿存在模块级 `Map` 里；回车检查 `event.isComposing`。
- 样式注入 id：`hp-user-quick-note-style`。

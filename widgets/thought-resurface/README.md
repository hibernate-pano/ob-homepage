# 闪念回顾 · `user-thought-resurface`

每天从旧日记里捞一条思考，让过去的记录重新出现在眼前。

| 项 | 值 |
|---|---|
| 文件 | `thought-resurface.js` |
| kind | `user-thought-resurface` |
| 图标 / 强调色 | `sparkles` / `#8b5cf6` |
| 默认尺寸 | 4×6 |
| 设置面板 | 有 |

## 功能

- 从旧日记里提取思考片段，每天固定推一条。
- 显示日期、距今天数、标签和来源文件；点击文字跳到原文对应行。
- 右上角「换一条」继续翻。
- 只读，不写任何笔记。

## 数据源

1. 日记里的 `## 思考` 小节：按空行/列表项切分，每条都算候选。
2. 正文里带 `#思考` / `#思考/xxx` 的行：即使没写在小节里也能被捞到。

只有 `minAgeDays` 天之前的思考会进入候选；不够时自动放宽到全部。

## 配置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `folder` | string | `日记` | 从哪个目录找；留空 = 全库 |
| `minAgeDays` | number | `7` | 只回顾至少这么多天前的思考；0 = 不限 |
| `minChars` | number | `15` | 太短的碎片不展示 |

## 实现备注

- 选取是确定性的：`hash(今天日期) % 候选数`，同一天刷新不会乱跳；「换一条」只是加偏移量。
- 候选按「文件数量 + 最新 mtime + 配置」做签名缓存 60 秒，避免每次重绘都读 700+ 篇日记。
- 标签会从正文里抽出来单独显示，正文里去掉标签和 Markdown 强调符。
- 样式注入 id：`hp-user-thought-resurface-style`。

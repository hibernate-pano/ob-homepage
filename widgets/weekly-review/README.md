# 本周复盘 · `user-weekly-review`

把「本周复盘写没写」和「上次复盘还欠什么」放到首页。

| 项 | 值 |
|---|---|
| 文件 | `weekly-review.js` |
| kind | `user-weekly-review` |
| 图标 / 强调色 | `calendar-check` / `#0ea5e9` |
| 默认尺寸 | 6×6 |
| 设置面板 | 有 |

## 功能

- 计算当前 ISO 周（如 `2026-W44`），检查 `复盘/周` 下是否已有对应文件。
- 没写时右上角出现「新建本周复盘」，按 `T-Week` 模板创建并打开。
- 列出本周复盘（没写时用上次）里未勾选的事项，可直接勾选。
- 显示今年已写多少篇、上次复盘隔了几周。

## 数据源

- 目录：`复盘/周`（可配置）。
- 文件名兼容 `2026-W44 周复盘.md` 和 `2026-W44.md`。
- 任务：文件里所有 `- [ ]` 行；勾选后改写为 `- [x]`。
- 新建模板：`系统/模板/T-Week.md`（可配置），支持 `{{date}}` / `{{date:FORMAT}}` / `{{time}}` / `{{title}}`。

## 配置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `folder` | string | `复盘/周` | 周复盘目录 |
| `template` | string | `系统/模板/T-Week.md` | 新建时使用的模板 |
| `limit` | number | `5` | 最多显示几条未完成事项 |

## 实现备注

- ISO 周用 `moment().format("GGGG-[W]WW")`；「隔了几周」用纯日期计算，避免 moment 严格解析的坑。
- 勾选前校验原始行内容，文件被别处改过就提示刷新，不盲改。
- 样式注入 id：`hp-user-weekly-review-style`。
